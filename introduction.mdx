Synapse Terraform Providers are a suite of three custom Terraform providers that let you deploy and manage GCP resources through [Identity-Aware Proxy (IAP)](https://cloud.google.com/iap) tunnels. Because Terraform resources are ephemeral, spinning up a long-lived IAP tunnel outside of Terraform and sharing it is not practical — these providers solve that by starting the IAP tunnel as part of the provider lifecycle, automatically tearing it down when the apply completes.

## How it works

<Steps>
  <Step title="Provider configures the IAP tunnel">
    When Terraform runs `apply`, the provider authenticates with GCP using your service account and starts an IAP tunnel to the specified bastion host instance. The tunnel listens on a random free local port.
  </Step>
  <Step title="Resources are created through the tunnel">
    All Helm or Kubernetes API calls are routed through the local proxy endpoint (`http://localhost:<port>`). Resources behave identically to the upstream Helm or Kubernetes provider.
  </Step>
  <Step title="Tunnel is torn down on destroy">
    When `terraform destroy` runs or the apply completes, the IAP tunnel is cleanly shut down. No long-running background processes are left behind.
  </Step>
</Steps>

<Note>
These providers require a GCP bastion host running a proxy (such as [tinyproxy](https://tinyproxy.github.io/)) that the IAP tunnel connects to. See the [bastion host setup guide](/guides/bastion-host-setup) for prerequisites.
</Note>
